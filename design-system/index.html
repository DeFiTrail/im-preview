WALLETALK DESIGN SYSTEM

Walletalk 设计系统

给 pc-web 换皮用的一整套设计与前端规范。PC 浏览器、Electron 桌面和 H5 共用一套渲染层，所以这里的令牌、组件和模板三端通用。技术栈按现有代码：React 18 · antd 5.10 · Tailwind 3 · SCSS Modules，只换皮，不改功能。

2 套主题：白天 / 黑夜74 个语义令牌 × 2 套取值78 个图标文字对比度 ≥ 4.5:1（两套主题逐对校验）antd 主题通过 5.10.3 类型检查

PC 会话页（40 顶栏 + 60 左栏 + 300 会话列 + 聊天窗）。右上角切换白天 / 黑夜，全站跟着变。所有数据均为演示数据。

默认跟随系统，个人设置里可切（见"IM 组件 · 个人设置"）。偏好存进现有的 appSettings，和语言一样持久化。

import { walletalkLight, walletalkDark, resolveWalletalkMode, watchSystemTheme }
  from "@/styles/walletalk-antd-theme";

const pref = useUserStore((s) => s.appSettings.theme ?? "system"); // "system" | "light" | "dark"
const [mode, setMode] = useState(() => resolveWalletalkMode(pref));
useEffect(() => {
  setMode(resolveWalletalkMode(pref));
  return pref === "system" ? watchSystemTheme(setMode) : undefined;
}, [pref]);
useEffect(() => { document.documentElement.dataset.theme = mode; }, [mode]);

基础 · 颜色与主题

白天是暖白纸，黑夜是深色皮面

两套主题用同一组令牌名，只换取值。大面积用 Paper / White / Night，墨黑做文字，琥珀只作点睛（标志规范建议 ≤ 15%）。唯一的例外是自己发的消息气泡用琥珀实色（项目方 2026-09-25 拍板），聊天页橙色占比会超过 15%，这是有意的选择，其余位置仍按点睛使用。钱包皮面在两套主题里都是深色，像一件实物。

琥珀色文字在白底上只有 2.5:1，所以浅色主题里的橙色文字一律用 Ember #B8470A（令牌 --wt-brand-text 已自动切换）；琥珀底上的文字用墨黑（7.45:1），不用白字。

品牌元素 · 钱包

皮面上有琥珀暗纹，卡片斜 11° 露出一角

来自标志的"会说话的钱包"。所有和钱有关的面板都用它：钱包页头部、转账 / 收款请求消息。四层结构：深色皮面 → 琥珀暗纹 → 11° 琥珀箔卡 → 扣环与圆点。暗纹是一圈圈钱包轮廓线，从卡片的位置向外扩散，一束暖光沿着纹路 14 秒走一轮；鼠标移上去，光跟着指针走、卡片抬起 5px，让人知道这张卡是可以操作的。

结构 .wt-wallet

<div class="wt-wallet wt-wallet--lg">
  <div class="wt-wallet__card"></div>      // 11° 琥珀箔卡
  <div class="wt-wallet__body">               // 皮面 + 暗纹（::before）
    …总资产…
    <span class="wt-clasp"><i class="wt-dot"></i>MPC 2/3</span>
  </div>
</div>

可调参数

  • --wt-wallet-gap：钱包所在区域的底色，做出卡片和皮面之间 3px 的空隙（标志里的 2.4u）
  • --wt-peek：卡片露出高度。大 40 · 中 30 · 消息 16
  • .is-ritual：加上即播放一次"卡片滑出"，动画结束后移除
  • .is-tracking + --wt-gx / --wt-gy：指针跟随（可选，示例见 app.js 的 wire 函数）
品牌元素 · 状态灯

扣环上的圆点，是界面里唯一会发光的东西

规范里"扣环代表安全，圆点是在线的灯"。在界面里它只有三种状态，对应的都是 pc-web 现有功能，不新增业务。浅色主题下圆点多一圈 Ember 外沿，保证白底上也有 3:1。

气泡尾巴

标志左下角向下、向外的那一笔就是气泡尾巴。对方的在左下，自己的镜像到右下；头像改为与气泡底部对齐（MessageItem 改 align-items: flex-end，纯样式）。原来"左上 4px 小圆角"的写法去掉。
