M1 · 数字翻牌

余额刷新、行情跳动时，只有变化的那几位数字滚动，其余不动。
参考：Transitions.dev · Number pop-in / Spinning counter
3

M2 · 角标弹入

热群来新消息，未读数从斜下方弹进来，带一点回弹。
参考：Transitions.dev · Notification badge

M3 · 处理中 → 到账

转账、发红包：文字模糊切换到"处理中"，确认后画出对勾。用户全程知道钱在哪一步。
参考：Transitions.dev · Text states swap / Success check

M4 · 卡片展开

点开红包、打开会话：卡片原地长大，里面的内容由模糊变清晰，不跳页。
参考：recent.design · Expanding Card（cz）

M5 · 遮罩揭示

隐藏余额、显示地址：被遮住的字符逐个淡入，而不是整块闪现。
参考：recent.design · Card Number Reveal（Nitish Khagwal）
