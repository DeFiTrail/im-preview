How it works

One wallet, every app.

Opens in the chat

Apps open full screen or as a half sheet, and one tap returns to the conversation.

Shares as cards

Any page can go to a friend or a group as a card that opens right where it was.

Asks before signing

Apps see the wallet address only after approval, and every signature asks first.

Reviewed before listing

Every app is reviewed before it reaches App Square, and risky ones carry a clear label.
