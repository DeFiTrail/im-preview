安全提示

Walletalk 永远不会索要这些。

客服、管理员和官方账号都不会索要以下任何一项。索要的，一律是诈骗。

  • 助记词或私钥
  • 钱包密码或备份密码
  • 无私钥钱包的恢复文件
  • 打开钱包时共享屏幕
  • 安装别人转发的链接或文件
好习惯
  • 只从本网站或官方应用商店下载，安卓安装包先核对 SHA-256。
  • 确认转账前，核对收款人和网络。
  • 私聊里催着要钱的，即使是熟悉的名字，也先当成危险信号。
  • 备份密码和恢复文件分开保存。

独立审计

钱包对外开放前会进行独立安全审计，审计报告将在本页公布。
