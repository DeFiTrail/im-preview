Account protection

Every sensitive step is guarded.

Password and biometrics

Everyday signing asks for the wallet password (12+ characters) or biometrics.

“Not me” alerts

Sensitive wallet actions send an email with a one-tap link that freezes signing.

48-hour security hold

Restoring on a new device starts a hold: funds can arrive, nothing can leave, and the old device is notified.

Scam signals in chat

Risk checks on brand-new accounts and bursts of friend requests help stop scams early.

Stay safe

What Walletalk will never ask for.

Customer Service, admins and official accounts never ask for any of these. Anyone who does is running a scam.

  • Seed phrase or private key
  • Wallet password or backup password
  • The Keyless Wallet recovery file
  • Screen sharing while the wallet is open
  • Installing an app from a forwarded link or file
Good habits
  • Download only from this website or official app stores, and check the SHA-256 of Android files.
  • Check the recipient and network before confirming a transfer.
  • Treat urgent requests for money in DMs as a red flag, even from familiar names.
  • Keep the backup password somewhere separate from the recovery file.
