Install help

Common install questions.

Android blocks the install. What now?

Android asks before installing apps from outside Google Play. Allow installs for the browser used to download (usually Settings → Apps → Special access → Install unknown apps; names vary by brand), install Walletalk, then turn the setting off again.

How do updates work?

On Android, Walletalk checks for new versions and shows an update prompt in the app. On iOS, TestFlight and the App Store handle updates.

Can one account run on several devices?

Yes. Messages sync across every device signed in to the account. An Identity Wallet is added to a new device with its seed phrase. A Keyless Wallet syncs from a device already in use, or is restored with its recovery file and backup password.

Which devices are supported?

iOS 16 or later, Android 6.0 or later, and current versions of Chrome, Safari, Edge and Firefox for the web app.
