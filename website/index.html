Two wallets

Keep the seed phrase.
Or skip it.

Two wallet types, side by side in one account. Either way, the platform alone cannot move wallet assets.

Recommended
Seed phrase
Identity Wallet
Self-held seed phrase · generated offline on this device
  • Back up by writing down 12 words
  • Keys are generated offline and never touch a server
  • Import with the seed phrase on a new device
No seed phrase
Keyless
Keyless Wallet
No seed phrase · key held in split shares
  • Nothing to write down
  • Set a backup password; the recovery file is emailed automatically
  • Sync from the previous device when switching

FAQ

Questions, answered in chat.

Is Walletalk free?
Walletalk
Yes. Chats and the wallet are free to use. On-chain transactions carry network fees, and Swap shows its fee before confirming. A paid membership with extra perks is on the way.
Who holds the keys?
Walletalk
An Identity Wallet’s seed phrase never leaves the device. A Keyless Wallet’s key is split into shares kept apart. Either way, the platform alone cannot move wallet assets.
Which networks are supported?
Walletalk
EVM networks such as Ethereum, BNB Chain, Base and Arbitrum, plus Solana and Tron.
How can I tell the app is official?
Walletalk
Download only from this website or official app stores. Each Android release lists a SHA-256 checksum here, so the file can be checked before installing.
Is there an iPhone app?
Walletalk
It’s coming to the App Store. Until then, the web app runs in Safari on iPhone.
