Why build on Walletalk

Distribution in chat

Any mini app page can be shared into a group or DM as a card. One tap opens it right there.

Wallet built in

Users connect with the Walletalk wallet. No extension, no QR pairing, and every signature is confirmed by the user.

Listed in App Square

Approved apps appear in App Square by category and ranking.

How it works

From idea to App Square in four steps.

  1. Apply

    Once access opens, request it from the web app with a Walletalk account.

  2. Build

    Ship a standard web app. The container provides the wallet through an EVM provider.

  3. Submit

    Submit the app for review with its name, icon, category and supported platforms.

  4. Go live

    Once approved, the app is listed in App Square and can be shared into any chat.

What the container provides.

window.addEventListener("eip6963:announceProvider", (e) => {
  const { info, provider } = e.detail;   // Walletalk

});

Risk labels

App Square shows a risk level for each app, so users know what they’re opening.

Review

What review looks for.

Before submitting

Each app is checked against these points before it reaches App Square.

  • Clear name, icon and description that match what the app does
  • No impersonation of other projects, brands or Walletalk
  • Fees and risks shown before the user confirms
  • No requests for seed phrases, private keys or passwords
  • Compliance with the laws where the app is offered
