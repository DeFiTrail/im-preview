Build where crypto communities talk.

Mini apps open inside Walletalk, connect to the wallet people already use, and travel through groups as cards.

Distribution in chat

Any mini app page can be shared into a group or DM as a card. One tap opens it right there.

Wallet built in

Listed in App Square

Approved apps appear in App Square by category and ranking, with official picks and featured slots.

How it works

From idea to App Square in four steps.

  1. 01

    Apply

    Request developer access from the web app with a Walletalk account.

  2. 02

    Build

    Ship a standard web app. The container provides the wallet through an EVM provider.

  3. 03

    Submit

    Submit the app for review with its name, icon, category and supported platforms.

  4. 04

    Go live

    Once approved, the app is listed in App Square and can be shared into any chat.

What the container provides.

window.addEventListener("eip6963:announceProvider", (e) => {
  const { info, provider } = e.detail;   // Walletalk
  provider.request({ method: "eth_requestAccounts" });
});
window.dispatchEvent(new Event("eip6963:requestProvider"));

Standard EVM provider

EIP-1193 requests with EIP-6963 discovery, so existing wallet code works with little change.

Full and half screen

Open full screen for deep flows, or as a half-height sheet over the chat.

Chat cards

Share any page as a rich card with title, image and a direct link back into the app.

User-approved access

Apps ask to connect before reading an address. Every signature and transaction is confirmed by the user.

Per-platform availability

Choose where an app is listed: Android, iOS and the web can be switched on separately.

Risk labels

App Square shows a risk level for each app, so users know what they’re opening.

Review

What review looks for.

  • Clear name, icon and description that match what the app does
  • No impersonation of other projects, brands or Walletalk
  • Fees and risks shown before the user confirms
  • No requests for seed phrases, private keys or passwords
  • Compliance with the laws where the app is offered
